# GameVault

Biblioteca virtual de videojuegos. Proyecto integrador de Ingeniería Web I.

## Tecnologías

HTML5 semántico, CSS3 (Flexbox, Grid, media queries) y JavaScript básico.

## Estructura

- `index.html`: página principal
- `css/styles.css`: estilos y diseño responsivo
- `js/main.js`: menú hamburguesa, catálogo con filtro y buscador, ficha modal, acordeón y validación del formulario
- `img/`: portadas ilustradas, logo e imagen principal (recursos propios en SVG)

## Cómo ejecutarlo

Abre `index.html` en el navegador. No requiere instalación.

Nota: los juegos del catálogo son ficticios.
